# Sound Files for Spinning Wheel

This directory contains sound effect files used by the spinning wheel application.

## Default Sounds

You need to add your own sound files in this directory with the following names:

- `tick1.mp3` - Default tick sound
- `tick2.mp3` - Alternative tick sound 1
- `tick3.mp3` - Alternative tick sound 2
- `tick4.mp3` - Alternative tick sound 3

## Sound Resources

You can find free sound effects at:

1. [Freesound.org](https://freesound.org/)
2. [Zapsplat](https://www.zapsplat.com/)
3. [Soundbible](https://soundbible.com/)

## Recommended Sound Types

For the wheel transitions, short "click", "tick", or "pop" sounds work best. Sounds should be:

- Short duration (less than 0.5 seconds)
- Small file size (under 100KB if possible)
- MP3 format for best browser compatibility
