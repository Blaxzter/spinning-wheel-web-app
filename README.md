# Spinning Wheel Web App

An interactive and customizable spinning wheel application for making random selections, decisions, or creating fun games of chance.

**Live Demo**: [https://wheel.fabraham.dev](https://wheel.fabraham.dev)

![Spinning Wheel Screenshot](https://github.com/user-attachments/assets/b02fa00a-a819-4f6e-a6ac-52186bf189f4)

## About

This Spinning Wheel Web App is a versatile and user-friendly tool that lets you create custom wheels with weighted options, colorful segments, and even images. It's perfect for:

- Making random decisions
- Classroom activities
- Team selection
- Giveaways and contests
- Games and entertainment

The application was built using v0 and Cursor AI, leveraging AI-assisted development to create a modern, responsive web application.

## Features

- **Customizable Options**: Add, edit, delete, and reorder wheel options
- **Option Weighting**: Assign different weights to options to control probability
- **Visual Customization**:
  - Multiple color palettes
  - Customizable text size and position
  - Upload images for wheel segments
- **Sound Effects**:
  - Customizable tick sounds when transitioning between options
  - Volume control for sound effects
  - Option to enable/disable sounds
- **Saving and Sharing**:
  - Save wheels to local storage
  - Share wheels via unique URLs
  - Predefined wheel templates
- **Advanced Features**:
  - Sorting options by name or weight
  - Randomize option order
  - Drag and drop reordering
  - Confetti animation for winners
- **Responsive Design**: Works on desktop and mobile devices

## Technology Stack

- **Framework**: Next.js 15
- **UI Components**: Shadcn/UI with Radix UI
- **Styling**: Tailwind CSS
- **State Management**: React Hooks
- **Animations**: Custom canvas-based animations

## Development

This project was created with the assistance of:

- **v0**: AI-assisted development platform
- **Cursor**: AI-powered code editor

### Prerequisites

- Node.js 22.15.0 or higher
- pnpm package manager

### Getting Started

1. Clone the repository
2. Install dependencies:
   ```
   pnpm install
   ```
3. Run the development server:
   ```
   pnpm dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Building for Production

```
pnpm build
```
